# Senior Node.js Engineer | UK FinTech Startup

## About the Position
Our client is a rapidly growing UK-based fintech company building next-generation digital solutions for trade and supply chain finance. They are seeking a Senior Node.js / TypeScript Engineer to design, build, and scale backend services within a microservices architecture. In this role, you will take end-to-end ownership of services, influence architecture and engineering standards, mentor other developers, and collaborate closely with Product, Security, Support, and DevOps.

## Key Responsibilities
* Design and implement scalable backend services using Node.js (NestJS) and TypeScript.
* Own critical business capabilities (invoices, payments, supplier lifecycle, funding decisions, audit trails) from discovery through production support.
* Build and maintain public APIs (REST/GraphQL) and internal service communication (gRPC), including versioning and backward compatibility.
* Drive architecture improvements, including service boundaries, event-driven workflows, data consistency, and resiliency patterns.
* Ensure security and compliance best practices (secure coding, dependency hygiene, secrets handling, auditability).
* Lead code reviews, enforce standards, and improve engineering quality (testing strategy, observability, CI/CD).
* Participate in on-call and incident response, contributing to post-mortems and reliability improvements.

## Main Requirements
* 5+ years of professional software engineering experience with a strong backend focus in Node.js and TypeScript/JavaScript in production.
* Proven experience with NestJS (or similar backend frameworks) and backend design patterns.
* Strong API design skills: REST best practices, pagination/filtering, authentication (JWT/OAuth), error modeling, and idempotency.
* Experience with microservices architecture and distributed system concerns (latency, consistency, retries, observability).
* Solid SQL skills and experience with PostgreSQL (schema design, query optimization, migrations).
* Experience with containers and delivery tools: Docker, CI/CD pipelines, and Git workflows.
* Strong communication skills in English to work with international teams.

## Nice-to-Have Skills
* Experience in fintech domains (payments, ledger/reconciliation, risk checks, audit trails, compliance, limits).
* Messaging and event streaming (Kafka) and patterns like outbox, CQRS, and Saga/workflow orchestration.
* Caching and performance tuning with Redis.
* AWS production experience (ECS/EKS, Lambda, SQS/SNS, S3, RDS, CloudWatch).
* Kubernetes and platform operations exposure.
* Security tooling and practices (dependency scanning, SAST/DAST, SOC2/ISO readiness workflows).

## Tech Stack
* **Backend:** Node.js, NestJS, TypeScript, microservices
* **APIs/Protocols:** REST, GraphQL, gRPC
* **Data:** PostgreSQL, Redis
* **Messaging:** Kafka (or similar)
* **Infrastructure:** Docker, Kubernetes
* **CI/CD:** GitHub Actions / GitLab CI
* **Observability:** CloudWatch, Prometheus/Grafana

## Recruitment Process
1. **Intro Call:** 30-minute online/phone interview with Itentio recruiters.

3. **Technical Interview:** 1 to 1.5-hour defense of your solution and technical discussion with the CTO.
